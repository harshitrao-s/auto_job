Put your exported cookie JSON files here:

  naukri_cookies.json     <- exported while logged in at naukri.com
  linkedin_cookies.json   <- optional, if you prefer cookies over a Chrome profile

How to export (Chrome):
  1. Install the "Cookie-Editor" extension.
  2. Log in to naukri.com (or linkedin.com) normally.
  3. Open Cookie-Editor on that tab -> Export -> "Export as JSON" -> copy.
  4. Paste into the matching file in this folder.

These files ARE your login session. They are gitignored. Do not share them,
and re-export when they expire (you will see the bot ask you to sign in).
